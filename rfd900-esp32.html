RFD900 + ESP32 ground station

Using MPXAir with the RFD900 / ESP32-S3 router board and its on-board GPS.

About the board

The board combines:

  • an RFD900 telemetry radio, linked to the aircraft's RFD900;
  • an ESP32-S3 that routes telemetry to USB and RC from an ELRS receiver to the aircraft;
  • a GPS module wired to the ESP32 (UART 115200 baud on GPIO7/6, PPS on GPIO8).

On the computer it appears as ttyACM0 · Espressif (USB ID 303a). Its own settings are changed with the board's GCS Settings page.

Connecting

  1. Plug the board in and pick ACM0 · Espressif at the top right. The ESP32's USB ignores the baud rate, so any value works.
  2. Press Connect. MPXAir releases DTR and RTS so the ESP32 isn't reset, and asks the board for its status.
  3. If the aircraft is on, it connects as usual. If not, the window says Ground station connected — waiting for the aircraft, and the ground GPS works straight away.
  4. The first time, the ground position switches to this board's GPS automatically.
One program at a time

The board's GCS Settings page and MPXAir can't use the USB port at the same time. Disconnect one before connecting the other.

What MPXAir reads

Once a second MPXAir sends #GCS status. The board answers with a line starting #GCS {, mixed into the telemetry. MPXAir uses:

FieldShown as
gps.fix, gps.sats, gps.hdopFix, satellites, HDOP
gps.lat, gps.lon (degrees × 10⁷), gps.altMmGround position and altitude
name, fwThe board's name and firmware on the Ground tab
followWhether the board is broadcasting its position to the aircraft

Follow mode

Turn on Ground station sends its position to the aircraft (Ground tab). This sends #GCS follow 1, and the board then broadcasts GLOBAL_POSITION_INT as system 255 twice a second. For ArduPilot's FOLLOW mode, set FOLL_ENABLE=1 and FOLL_SYSID=255 on the aircraft.

Cold starts

The board's GPS has no backup battery, so every power-up is a cold start. Allow a few minutes with a clear view of the sky for the first fix.
