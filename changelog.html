What's new

Changes in each version of MPXAir.

1.2.3

  • Disconnect asks for confirmation (with a stronger warning if the aircraft is armed), then closes the serial port completely and confirms it is free for other programs.
  • While connected, MPXAir has the port to itself, so other programs get a clear "busy" error. If another program already has the port open, MPXAir names it.
  • Fixed: the heartbeat could be written while the port was closing.

1.2.2

  • Fixed: the firmware version was sometimes never learned on a busy radio link, so matching parameter descriptions weren't used. It's now requested until it arrives, and read from the startup banner as a fallback.
  • Fixed: a step in the connection and Plan progress windows could stay on "reading…".
  • The GROUND label moves above its badge when the aircraft is right next to the ground station.
  • mpxair --connect starts and connects to the last-used device.

1.2.1

  • Fixed: a stray diagonal line on the HUD next to the pitch ladder; the ladder now covers ±90° with dashed rungs below the horizon.
  • Fixed: dropdowns showing no value when their first option was selected (e.g. Ground station type, parameter values).
  • Fixed: the window opening wider than the screen, which hid the right-hand panels.
  • Parameter descriptions matched to the aircraft's exact firmware version, a clearer description panel (What it does, options), and descriptions in the list.
  • Ground GPS card at the bottom-right of the Fly map. The GROUND marker stays at its last known position when the fix is lost.
  • Clearer ground station panel (board, GPS, radio links, health), more robust reading of board replies.
  • Automatic reconnect when a USB device drops off and comes back.
  • "3D Fix + DGPS" instead of "DGPS", and a smaller map credit.

1.2.0

  • Ground station types: RFD900 + ESP32, GPS in the telemetry (NMEA/MAVLink), MAVLink GPS from the ground station, and custom boards with JSON or comma-separated replies. Each type has its own editable settings, with Test now and the last message received.
  • This documentation website.

1.1.0

  • Connection and Plan read/write progress windows.
  • Quick view with 2–16 tiles and 45 values.
  • Parameter groups sidebar, and hover descriptions everywhere.
  • Adjustable, auto-clearing flight trail, and the GPS card at the bottom-left of the map.
  • Readable dropdowns and the Internet use choices.

1.0.0

First public release: Fly, Plan, Setup, Parameters, Logs and Ground, the RFD900 + ESP32 board, offline maps, and the installer.

Full details are in CHANGELOG.md.
