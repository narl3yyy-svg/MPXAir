Before you start

Use a USB cable straight to the flight controller, not a telemetry radio. Don't unplug it while it's being written.

Install from ArduPilot's list

  1. Open Setup → Install firmware.
  2. Choose the Vehicle type (Copter, Plane, Rover, Sub, Helicopter, Antenna tracker, Blimp) and the Release:
    • Stable;
    • Beta;
    • Latest (development).
  3. Press Detect board. If you're connected, MPXAir restarts the board in bootloader mode. Otherwise, plug the board in within 30 seconds. The board ID is filled in for you.
  4. Press Find firmware, select a build, and press Install selected firmware.
  5. MPXAir downloads, erases, writes and verifies the firmware (with a CRC check), then reboots the board. Wait about 10 seconds and connect again.

Install your own file

Press Load a .apj file… and choose an ArduPilot .apj firmware file. MPXAir checks that it matches the board before writing.

How it works

MPXAir speaks the same bootloader protocol as Mission Planner and ArduPilot's uploader.py. The firmware list comes from firmware.ardupilot.org/manifest.json.gz and is cached for 24 hours.

Tested

The uploader was tested against a simulated bootloader with a 1.6 MB CubeOrange image, verified byte for byte. Test it on a board you can recover the first time.
