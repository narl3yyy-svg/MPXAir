Finding a parameter

  • Groups (left): browse by subject, such as Battery (BATT), Failsafes (FS), Servo / motor outputs (SERVO) and EKF3 (EK3), without knowing the exact name. Small groups are under Other.
  • Search: type part of the name or of the description, such as rtl alt or battery capacity. Searching always looks at every parameter.
  • Filter: All, Changed (not yet written), Standard or Advanced.
  • Hover over any row to see what it does.

Changing parameters

  1. Select a parameter. The editor on the right shows its description, units, range and a control: a dropdown for named values, switches for bitmasks, or a number field.
  2. Press Keep change to collect it (changed values are highlighted), or Write now to send it straight away.
  3. Press Write changes at the top to send everything you collected. If any parameter needs a reboot, MPXAir offers to do it.

Files

  • Save… writes every parameter to a .param file (Mission Planner format).
  • Load… reads a Mission Planner, MAVProxy or QGroundControl file. It compares it with the aircraft and stages only the differences for you to review. Calibration and counter values are never overwritten.

Descriptions

MPXAir ships descriptions for every ArduPilot parameter. Newer firmware adds parameters. Preferences → Telemetry → Update downloads ArduPilot's latest descriptions.
