Requirements

  • Ubuntu 24.04 or newer. It is developed and tested on Ubuntu 25.10. Other Linux desktops with GTK 4.12+ and libadwaita 1.4+ also work.
  • Python 3.10 or newer and these Ubuntu packages, which a standard Ubuntu desktop normally already has: python3-gi, python3-cairo, gir1.2-gtk-4.0, gir1.2-adw-1.
  • Optional: gir1.2-geoclue-2.0, to use the computer's location service as the ground position.

Get MPXAir

git clone https://github.com/narl3yyy-svg/MPXAir.git
cd MPXAir

Or download the ZIP from the GitHub page (Code → Download ZIP) and unpack it.

Run it without installing

./run.sh
CommandWhat it does
./run.shStart MPXAir. Settings go in ~/.config/mpxair, missions and logs in ~/Documents/MPXAir.
./run.sh --portableKeep settings, map cache and logs inside the folder (userdata/). Good for a USB stick you carry between computers.
./run.sh --connect or mpxair --connectStart and connect straight away to the last-used device.
./run.sh --demoRun only the demo drone in the terminal (tcp:127.0.0.1:5790). Useful for testing other ground stations.

If something is missing, run.sh says exactly which packages to install.

Install it

./install.sh
  1. It checks the Ubuntu packages and offers to install any that are missing with apt. Only then does it ask for your password.
  2. It copies MPXAir to ~/.local/share/mpxair.
  3. It adds an MPXAir launcher to the app grid and an mpxair terminal command.
  4. It offers to add you to the dialout group, which is needed for USB flight controllers and radios. Log out and back in afterwards.

To install for every user on the computer, use ./install.sh --system, which installs to /opt/mpxair.

Update

cd MPXAir
git pull
./install.sh

Your settings, maps and logs are kept.

Uninstall

./uninstall.sh

Use ./uninstall.sh --system for a system-wide install. Your settings (~/.config/mpxair), map cache (~/.cache/mpxair) and logs (~/Documents/MPXAir) are left in place.

USB access

If MPXAir says Permission denied when opening a USB port, run sudo usermod -aG dialout $USER, then log out and back in.
