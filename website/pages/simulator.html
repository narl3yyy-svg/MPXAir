Build SITL

Follow ArduPilot's Linux build guide, then build the vehicle you want:

cd ardupilot
./waf configure --board sitl
./waf copter

Run it

./build/sitl/bin/arducopter --model quad --home -35.363261,149.165230,584,353 --defaults Tools/autotest/default_params/copter.parm -I0

In MPXAir choose TCP, enter 127.0.0.1:5760 and press Connect.

What to try

  • Wait for GPS: 3D Fix (bottom-left of the map), then use Takeoff and Fly to here.
  • Write a mission on Plan and press Start Mission.
  • After landing, download and graph the log on Logs.
