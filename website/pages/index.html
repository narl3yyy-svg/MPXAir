MPXAir documentation

Plan, fly, set up and review ArduPilot drones, planes, rovers and boats from Ubuntu. It uses the same screens and files as Mission Planner, rebuilt as a fast, native Linux app.

📡

Why MPXAir

  • Familiar. The same workflow as Mission Planner, with the same .waypoints and .param files, parameter descriptions and mission commands.
  • Native and modern. GTK 4 and libadwaita, light and dark styles, small-screen and touch friendly.
  • Self-contained. No downloads from outside sources. Everything it needs ships with Ubuntu. The MAVLink protocol, map engine, log reader and firmware uploader are all part of MPXAir.
  • Ground station aware. It reads the GPS of your ground station (for example an RFD900 + ESP32 board) and shows the aircraft and the ground station side by side.

Where to start

  1. Install MPXAir, or just run it from its folder.
  2. Take the quick tour with the built-in demo drone. You don't need any hardware.
  3. Connect your aircraft over USB, a telemetry radio, UDP or TCP.
  4. Check the setup and calibration pages before the first flight.
