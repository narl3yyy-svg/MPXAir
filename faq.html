Help

Questions and answers

Short answers to common questions.

Does MPXAir work with PX4?

No. MPXAir is made for ArduPilot (Copter, Plane, Rover, Sub, Antenna tracker).

Can I use my Mission Planner files?

Yes. MPXAir reads and writes .waypoints missions and .param files in Mission Planner's format, and it reads QGroundControl and MAVProxy parameter files.

Does it need the internet?

Only for map tiles, downloading firmware and updating parameter descriptions. Save map areas with Offline Maps before going to the field.

Where are my files?

Telemetry recordings are in ~/Documents/MPXAir/telemetry-logs, downloaded logs in ~/Documents/MPXAir/flight-logs, settings in ~/.config/mpxair, and maps in ~/.cache/mpxair.

Can I run it from a USB stick?

Yes, with ./run.sh --portable. Everything is then kept in the MPXAir folder.

Can I use it alongside another ground station?

Not on the same serial port, because only one program can open it. Use UDP or TCP forwarding (for example from MAVProxy) to share a link.

What's not in MPXAir yet?

Joystick control, a video feed, scripting, multiple vehicles at once, and some specialist setup screens. Those settings can still be changed on the Parameters tab.
